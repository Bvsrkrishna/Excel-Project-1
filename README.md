# Hospital Readmission Analysis – Excel Project

## Project Overview
This project focuses on analyzing hospital patient readmission data using Microsoft Excel. It aims to explore patient information, identify readmission patterns and present key healthcare metrics through an interactive dashboard.

## Objectives
- Analyze hospital patient readmission patterns.
- Understand patient demographics and admission trends.
- Explore key factors associated with readmissions.
- Summarize healthcare data using meaningful KPIs.
- Present findings through an interactive Excel dashboard.

## Tools & Technologies
- Microsoft Excel
- Excel Formulas and Functions
- Pivot Tables
- Data Cleaning
- Data Analysis
- Data Visualization
- Interactive Dashboard

## Project Files
- `Hospital_Readmission_Dashboard.xlsx` – Excel analysis and dashboard.
- `Excel - Hospital Administration Analysis.pdf` – Project report and documentation.

## Key Skills Demonstrated
- Data Cleaning and Preparation
- Exploratory Data Analysis
- KPI Reporting
- Pivot Table Analysis
- Dashboard Development
- Data Visualization
- Analytical Thinking

## Project Outcome
Developed an Excel-based hospital readmission analysis dashboard to organize healthcare data, explore readmission patterns, and communicate key metrics through visual reporting.

## Conclusion
This project demonstrates practical Microsoft Excel skills applied to healthcare data analysis and dashboard reporting.
